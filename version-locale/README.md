# Version locale — hors ligne

Ouvrir `Editeur_Equipements_Fonctions_V4_local.html` dans un navigateur compatible.

- Application V4 autonome : aucune bibliothèque JS téléchargée, aucune dépendance réseau.
- Motif par défaut : deux lettres, cinq chiffres, et une lettre finale facultative (ex. `AA00200`, `AA00200P`).
- Extraction PDF expérimentale à partir des octets et des flux décompressables du fichier : la détection n'est pas garantie sur tout PDF.
- Fonctions et allocations conservées selon la logique V4.
- **Ce n'est pas une adaptation complète de V5.8.3** : pas d'interactivité géométrique PDF, pas de lasso ni de gestion avancée XLSX comparable à la version complète.

Cette édition est la **base de développement locale**, destinée à être enrichie. Tester la lecture et les exports avec des fichiers réels.
